====================================================================
WHY THIS FILE WAS REWRITTEN
====================================================================
The first audit closed with "PASS. No load-bearing asset lives outside
the project directory." That was wrong.

`ReflexCore/Sources/ReflexCore/LiveTranscriber.swift` still resolved
the models directory as:

    FileManager.default.homeDirectoryForCurrentUser
        .appendingPathComponent("Development/Reflex/Models")

`~/Development/Reflex` was deleted during the integration. Proven, not
inferred — `reflex-cli --diagnose` reported:

    x Whisper model: whisper-small models not found in
      /Users/emir/Development/Reflex/Models
    1 blocking issue(s)

Two things were wrong, and the second is the serious one:

  1. A live bug. The app's Diagnostics button and `--diagnose` both
     read a path that does not exist. Transcription still worked,
     because AppModel used a different, correct resolver — which is
     exactly why it survived: a false alarm, not a crash.

  2. The audit's own method had a blind spot. It grepped for the
     literal string `/Users/`. This path is assembled from two tokens
     and never appears literally, so the grep passed clean over it.
     The audit then wrote "ALL rewritten... No $HOME assumption
     remains in any load-bearing path" and listed only two intentional
     hits. Six of seven paths were fixed and the seventh was reported
     as zero remaining.

Lesson recorded in ATLAS.md Decisions: audit the API, not the string.

====================================================================
FIX
====================================================================
One resolver, three callers.

  ReflexWhisperKit.defaultModelsDirectory   (ReflexCore, the source of truth)
    |- ReflexEnvironment.modelDirectory()   (Reflex app + the bundle fallback)
    \- defaultModelsDirectory()             (reflex-cli)

All now derive `Models/` from `#filePath`, never from `$HOME`. The app
wrapper keeps only the one thing that is genuinely app-specific: the
`Bundle.main.resourceURL` fallback for a shipped `.app` carrying its own
weights.

Files changed:
  ReflexCore/Sources/ReflexCore/LiveTranscriber.swift   resolver rewritten
  ReflexCore/Sources/ReflexCLI/main.swift               now delegates
  Reflex/ReflexApp.swift                                now delegates (+ import)
